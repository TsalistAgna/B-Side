# B-Side

B-Side is an iOS app that uses Apple Foundation Models to help users understand, organize, and rediscover screenshots with less cognitive effort.

Instead of asking users to manually create folders, tags, or notes, B-Side tries to understand **why a screenshot may have been saved** and preserves that context for later.

## Challenge

Explore how Apple Foundation Models can understand and categorize screenshots to create an AI experience that reduces cognitive load, simplifies decisions, and helps users find meaning in what they save.

## Core User Problem

People often use screenshots as a quick way to save information, but over time they can lose the context of why those screenshots were saved.

This makes useful information harder to understand and rediscover, forcing users to remember details such as:

- when the screenshot was taken
- where it came from
- what was inside it
- why it was saved
- what they intended to do with it later

## How Might We

**How might we help users rediscover the purpose and context of their saved screenshots without requiring them to manually organize or remember them?**

## Solution Concept

B-Side combines three ideas:

### 1. Context Preservation

When a screenshot is analyzed, AI generates lightweight context such as:

- a short title
- a rediscovery message
- a detail description
- relevant tags
- a purpose-based category

The goal is to preserve meaning without requiring the user to manually add metadata.

### 2. Search by Memory

Users should be able to search using the way they naturally remember things.

Examples:

- “that cafe I saved in Bali”
- “the black shoes I wanted to buy”
- “UI inspiration for onboarding”
- “the event I screenshotted last month”

The experience focuses on meaning and context instead of requiring exact keywords, dates, or filenames.

### 3. Daily Rediscovery

B-Side can occasionally resurface useful or forgotten screenshots from the user’s collection.

This creates a lightweight moment of discovery without requiring users to actively search through old screenshots.

## AI Role

AI acts as a **context-preserving assistant**.

It should:

- understand screenshot content
- infer the likely future value of a screenshot
- generate useful context automatically
- organize screenshots by likely purpose
- support natural-language rediscovery
- stay unobtrusive when user input is not needed

The design principle is:

> **Automate the obvious. Suggest the uncertain. Let the user decide the personal.**

## AI Failure Handling

AI should act automatically when the result is:

- low risk
- reversible
- supported by clear evidence
- unlikely to interrupt the user

When intent is unclear, B-Side should:

- use broader or neutral wording
- avoid inventing personal motivations
- avoid presenting uncertain intent as fact
- allow lightweight correction
- keep the original screenshot unaffected

If AI is wrong, the experience should follow:

**Wrong → Easy to notice → Easy to correct → No damage done**

## B-Side Terminology

### Track

A **Track** represents an individual screenshot enriched with contextual information generated by AI.

A Track may contain:

- title
- screenshot
- rediscovery description
- detail description
- tags
- category

### B-Side

A **B-Side** is a meaningful grouping of related Tracks.

The name is inspired by music and vinyl terminology, where individual saved items become part of a larger collection.

- Inspiration
- Food & Recipes

- Conversations
- Work & Study
- Travel

- Finance

- Memes & Fun
- Read Later

Categories represent **why the screenshot may be useful later**, while tags describe the specific content or context.

Example:

```text
Category:
Things to Buy

Tags:
Nike
Pegasus
Running Shoes
```

## Design Principles

### Reduce decisions

Users should not need to categorize, rename, or tag every screenshot manually.

### Preserve context

The app should help users understand why something may have mattered when they saved it.

### Keep AI in the background

AI should provide value without constantly asking for confirmation.

### Preserve user control

Users should always be able to correct AI-generated context when needed.

### Prefer lightweight interactions

Temporary and focused interactions, such as adding a B-Side or inspecting Track details, can use sheets to preserve browsing context and reduce unnecessary navigation.

### Avoid over-organization

The goal is not to create a more complicated folder system. The goal is to make saved information easier to rediscover.

## Technology

- Swift
- SwiftUI
- Apple Foundation Models
- FoundationModels
- structured generation with `@Generable` and `@Guide`

## Current Project Focus

The current design process focuses on:

1. defining the core user problem
2. reducing cognitive load
3. defining the role and boundaries of AI
4. preserving screenshot context
5. supporting natural-language rediscovery
6. exploring lightweight daily rediscovery
7. validating the experience through user flows, lo-fi prototypes, and usability testing

## Product Flow

```text
Screenshot
    ↓
AI understands content
    ↓
AI infers likely purpose
    ↓
Context is preserved
    ↓
Track becomes searchable and understandable
    ↓
User forgets about it
    ↓
Search by memory / Daily Rediscovery
    ↓
Screenshot is rediscovered
```

## Status

B-Side is currently in the product design and prototyping phase.

The Foundation Models capability has been explored through an initial prototype, and the project is now focused on translating those technical learnings into a user experience that genuinely reduces cognitive load.
